## 🚨 Capstone Project Details

### Project Title
> **PNP Emergency Incident Management System**

A web-based system designed to streamline the recording, monitoring, and resolution of emergency incidents reported to PNP units — enabling faster response and real-time administrative oversight.

---

### 📊 Primary Data Fields (Record Table)

| # | Field Name | Description |
|---|-----------|-------------|
| 1 | **Incident ID** | Unique identifier for each reported emergency case |
| 2 | **Reporter Full Name** | Name of the person who filed the incident report |
| 3 | **Incident Type** | Category of emergency (e.g., Crime, Accident, Missing Person) |
| 4 | **Location / Barangay** | Address or area where the incident occurred |
| 5 | **Responding Officer** | PNP officer assigned to handle the case |
| 6 | **Status / Action** | Current state of the incident (Open, Ongoing, Resolved, Closed) |

---

### 📈 Key Performance Indicators (KPIs) — Admin Dashboard

| # | KPI | Description |
|---|-----|-------------|
| 1 | 🔴 **Total Active Incidents** | Total number of currently open or ongoing emergency cases |
| 2 | ✅ **Cases Resolved Today** | Number of incidents successfully closed within the current day |
| 3 | ⚡ **Average Response Time** | Average time (in minutes) from incident report to officer dispatch |

---

> [!TIP]
> These KPIs give the admin a real-time snapshot of unit performance, workload, and response efficiency.
